1 .MODELOS PROBABILISTICOS

Los modelos discretos probabilísticos son herramientas de la probabilidad que se usan para describir situaciones donde los resultados posibles son contables (no infinitos continuos), es decir, se pueden enumerar uno por uno.

Los modelos probabilísticos se clasifican principalmente según el tipo de valores que pueden tomar las variables y cómo se comporta el fenómeno.

1. Según el tipo de variable

a) Modelos Discretos

Se usan cuando los valores son contables (enteros).

Ejemplos:

  • 0, 1, 2, 3 personas
  • Número de llamadas
  • Cantidad de errores

Modelos típicos:

  • Binomial
  • Poisson
  • Hipergeométrica

b) Modelos Continuos

Se usan cuando los valores pueden ser cualquier número dentro de un intervalo (incluye decimales).

Ejemplos:

  • Tiempo (1.2 horas, 3.75 min)
  • Peso (70.5 kg)
  • Estatura

Modelos típicos:

  • Normal
  • Exponencial
  • Uniforme continua

Modelos Probabilisticos Discretos

Distribucion Binomia

La distribución binomial es un modelo probabilístico discreto que permite calcular la probabilidad de obtener un número específico de éxitos en un conjunto de ensayos independientes, donde cada ensayo tiene únicamente dos posibles resultados: éxito o fracaso.

Características de la distribución binomial

  1. Número fijo de ensayos (n): El experimento se repite un número determinado de veces.

  2. Dos resultados posibles: En cada ensayo solo puede ocurrir:

    • Éxito
    • Fracaso

  3. Probabilidad constante (p): La probabilidad de éxito se mantiene igual en todos los ensayos.

  4. Independencia de los ensayos: El resultado de un ensayo no influye en los demás.

  5. Variable aleatoria discreta: La variable representa el número de éxitos obtenidos y solo puede tomar valores enteros (0, 1, 2, ..., n).

Función de probabilidad

La probabilidad de obtener exactamente ( k ) éxitos en ( n ) ensayos está dada por:

P(X=k)=\binom{n}{k} p^k (1-p)^{n-k}

Donde:

  • ( n ): número total de ensayos
  • ( k ): número de éxitos
  • ( p ): probabilidad de éxito
  • ( (1 - p) ): probabilidad de fracaso
  • \binom{n}{k}: combinaciones de ( n ) elementos tomados de ( k ) en ( k )

Media y varianza

La distribución binomial tiene las siguientes medidas:

Media (valor esperado):

\mu = np

Varianza:

\sigma^2 = np(1-p)

Desviación estándar:

\sigma = \sqrt{np(1-p)}

3 .Distribucion de Poisson:

La distribución de Poisson es un modelo de probabilidad que se utiliza para contar cuántas veces ocurre un evento en un intervalo fijo de tiempo, espacio o área.

Ejemplos típicos:

  • Número de llamadas en un call center
  • Accidentes en una fábrica
  • Clientes que llegan a un negocio

Fórmula

[ P(X = x) = \frac{e^{-\lambda} \lambda^x}{x!} ]

Donde:

  • ( X ) = número de eventos
  • ( \lambda )= promedio de ocurrencias
  • ( x ) = número de eventos que queremos calcular
  • ( e )= constante ≈ 2.71828

*Características principales**

1.Variable discreta

Solo toma valores enteros: $ 0, 1, 2, 3, …$

  1. Depende de un solo parámetro

( \lambda ) (media o promedio)

  1. Media y varianza

Media = λ Varianza = λ

Esto es clave: ambas son iguales

  1. Eventos independientes

Que ocurra un evento no afecta a otro.

  1. Ocurre en intervalos fijos

Tiempo, distancia, área, etc.

  1. Probabilidad de ocurrencia constante

La tasa (λ) no cambia en el intervalo.

  1. Eventos raros

Se usa mucho cuando los eventos no son muy frecuentes.

Cuándo usar Poisson

Se usa cuando:

  • Se cuentan eventos
  • Ocurren de forma aleatoria
  • Se conoce el promedio (λ)
  • Se analiza un intervalo fijo

4 .Distribucion Hipergeometrica

La distribución hipergeométrica es una distribución de probabilidad discreta que se usa cuando se seleccionan elementos sin reemplazo de una población finita.

¿Cuándo se usa?

Se aplica cuando:

  • Hay una población total finita (N)

  • Existen dos tipos de elementos:

    • Éxitos (K)
    • Fracasos (N − K)

  • Se extrae una muestra sin reemplazo (n)

  • Se quiere saber la probabilidad de obtener x éxitos

Fórmula

P(X=x)=\frac{\binom{K}{x}\binom{N-K}{n-x}}{\binom{N}{n}}

Significado de cada símbolo

  • (N): tamaño de la población
  • (K): número de éxitos en la población
  • (n): tamaño de la muestra
  • (x): número de éxitos que queremos obtener

Idea clave

La probabilidad cambia en cada selección porque NO hay reemplazo

Esto la diferencia de la binomial, donde sí hay reemplazo o independencia.
